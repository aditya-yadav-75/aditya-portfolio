## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/aditya-yadav-75/aditya-portfolio.git
```

Navigate to the project:

```bash
cd aditya-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
